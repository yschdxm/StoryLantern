# 叙灯 · Story Lantern

一个**手机优先**的小说 / 角色扮演客户端：本地优先、内容加密同步、零第三方运行时依赖。
中文界面，个人自用的开源项目。

- **本地优先**：数据先落在自己设备上；同步只走"哑存储"（网盘目录 / WebDAV / S3 兼容存储 / 局域网共享），
  服务端看不到明文 —— 内容在离开设备前就已加密。
- **一切皆插件**：内核之外没有非插件代码，核心功能与第三方功能用**同一套扩展点**。
- **可解释的上下文**：每次发给模型的内容由"块图"装配，每块都能看到"为什么在/为什么被裁掉"。
- **调优只提案**：自动整理记忆/摘要只产出**提案**，必须你点"应用"才写入，且随时可撤销。
- **可核对**：每个数字都能用仓库里的脚本复现（见下）。

## 一、怎么拿到它

目前**还没有正式发布的版本**（不打 tag、不发 Release）。两种用法：

**A. 从 GitHub Actions 的产物安装（推荐给只想用的人）**

1. 打开 `Actions` → 选 `release-test` → `Run workflow`（或下载最近一次成功运行的产物）；
2. 在 Artifacts 里下载 `android-test`，得到一个 `.apk`（**测试包**，包名 `app.storylantern.test`，
   显示名"叙灯·测试"，可与正式包共存）；
3. 传到手机上安装。Android 可能提示"未知来源"，需要在系统里允许一次。

**B. 自己从源码构建**（开发者）：见 [DEVELOPMENT.md](DEVELOPMENT.md)。

> 桌面端（Windows / macOS / Linux）也支持，但同样没有正式发布包，需要自己构建，
> 且**不买代码签名证书**，所以系统会弹 SmartScreen / Gatekeeper 警告 —— 用第六节的校验和自证来源。

## 二、第一次使用

1. **配置模型服务**：设置 → 模型服务 → 填「接口地址」与「API Key」。
   - 任意 OpenAI 兼容端点都行（官方 DeepSeek、OpenAI、或你本机的推理服务）；
   - **API Key 只存在宿主数据库里**（不写前端日志、不进同步、不进仓库），界面上只显示掩码；
   - 改完离开输入框即自动保存；点「测试连接」可以立刻验证。
2. **选角色**：可以导入角色卡（PNG / CHARX / JSON 等，见下）。
3. **开始聊**：会话页点「+」建会话；每行的 ⋯ 可以重命名、删除；聊天页顶部 ⋯ 里有「长期记忆」「设定库」。

## 三、日常里会用到的几件事

| 想做什么 | 在哪里 |
|---|---|
| 让角色"一直记得"某件事 | 聊天页 ⋯ → **长期记忆**（可设关键词：没关键词的当常量，每轮都在场） |
| 整理长对话 | 长期记忆 → **重算分层摘要**（会明确显示"已写入 N 条摘要"，用量标注为**估算**） |
| 自动整理出可合并/可清理的条目 | 设置 → **调优助手** → 重新分析 → 逐条"应用"（随时"撤销"，内容回到应用之前） |
| 世界书 / 设定 | 「世界书」页；支持导入独立世界书文件 |
| 导入角色卡与聊天记录 | 设置 → 数据 → **导入**（PNG/APNG、CHARX、JSON、聊天 JSONL、预设等；正则脚本按设计**不导入**，界面会说明） |
| 把全部内容备份成一个文件 | 设置 → 整体备份 → **选择目录并导出**（自包含的 `.slbak`） |
| 从备份恢复 | 设置 → 整体备份 → **选择目录并恢复**（会挑目录里**最新**的 `.slbak`；它不是覆盖导入：日志只追加、重复 op 会被认出来） |
| 多设备同步 | 设置 → 同步（见下一节） |
| 看当前发了什么给模型 | 聊天页顶部的 Request Inspector（每块都带"为什么在"的理由） |

## 四、同步怎么配

同步把加密后的内容放进一个"哑存储"，另一端读回来 —— **存储方看不到明文**。

| 后端 | 怎么配 | 备注 |
|---|---|---|
| **本地/局域网文件夹** | 设置 → 同步 → 选目录 | 最省事；SMB 共享目录也能用 |
| **WebDAV**（Nextcloud、坚果云、InfiniCLOUD…） | 填 URL + 账号 + 应用专用密码 | 各家入口见它们自己的官方文档；本项目的用法就是标准 WebDAV |
| **S3 兼容** | 填 endpoint / bucket / key | 自写 SigV4 签名，无第三方依赖 |

同步的几条实话：

- 同步口令是**打开你自己设备门**的东西；请只与你信任的人共用（组内权限是对等的）；
- 踢掉一台设备 = **不再给它套锁**（它拿不到以后的新内容）；**它以前下载过的副本无法收回** —— 任何设计都做不到；
- 空间回收很保守：只回收本机自己发布的段，默认 30 天宽限期，且要你手动确认。

## 五、备份与恢复的三条真心话

导出的 `.slbak` 里是**整份操作日志**（自包含，重放即可重建），所以：

- 远端 op 日志**不是备份**（网盘删了就没了）；请定期导出一份到你自己的地方；
- 恢复是**追加**：重复的 op 会被识别，不会覆盖你现在的数据；
- 三种失败都会**明确报错**（选到没有备份的目录 / 选到损坏的文件 / 取消选择），不会"导一半"。

## 六、核对下载与来源

正式产物会附 `SHA256SUMS`；装了 GnuPG 的话还会附 `SHA256SUMS.asc`（用发布者公钥验签）。
**没有代码签名证书**是刻意的选择（个人非商业项目不买证书），所以：

- Windows SmartScreen / macOS Gatekeeper **会警告** —— 那是操作系统按"发行者身份"给信任，与文件本身是否完整是两件事；
- 你能核对的是：**哈希一致**（文件没坏/没被换）+ **清单签名一致**（清单没被人动过）。

```bash
sha256sum -c SHA256SUMS          # Linux
shasum -a 256 -c SHA256SUMS      # macOS
# Windows PowerShell: Get-FileHash -Algorithm SHA256 <文件>  （与清单里的值比对）
gpg --verify SHA256SUMS.asc SHA256SUMS   # 需要发布者公钥
```

## 七、隐私与安全

- 数据默认只在本机；同步内容是**端到端加密**的（密钥只在设备间分发，网盘上只有密文）；
- API Key、同步口令只存在**宿主数据库 / 设备本地存储**里，界面只显示掩码；
- 仓库里**不含**任何密钥、口令或用户数据；
- 手机上的"整体备份"文件本身**没有加密**，请自行妥善保管（或放进你自己的加密盘）。
